# Memory Management in Operating Systems – Interactive Visualizer

A single-page, interactive presentation for a 2nd-year B.Tech CSE class. Built with plain HTML, CSS and JavaScript. No frameworks, no dependencies, works offline.

## Topics covered
1. Introduction (CPU, RAM, OS, loading programs)
2. Memory allocation (fixed and variable partitioning, internal and external fragmentation)
3. First Fit, Best Fit, Worst Fit
4. Paging (page table, logical to physical address translation)
5. Segmentation (base and limit)
6. Virtual memory and demand paging (page faults)
7. Page replacement (FIFO, LRU, Optimal)
8. Thrashing
9. Summary

## How to run
Open `index.html` in Chrome (double-click). Use the top tabs or the left/right arrow keys to move between topics.

## Host on GitHub Pages
Repository **Settings → Pages → Deploy from a branch → main / (root)**. The site will be available at `https://<your-username>.github.io/<repo-name>/`.
